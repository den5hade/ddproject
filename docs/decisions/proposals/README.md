## Process

1. Proposal created in `proposals/`
2. Team reviews, discusses, refines
3. If accepted → promoted to `ADR-XXX-*.md` in parent directory
4. If rejected/superseded → archived with note

See `docs/decisions/ADR-001-monorepo.md` for ADR template.
